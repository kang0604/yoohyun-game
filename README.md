# 이유현 키우기 🍗

사방에서 날아오는 음식을 먹으며 이유현을 키워보세요!  
배가 부를수록 몸집이 커지고, 커진 몸은 피하기 어려워집니다.

**[🎮 게임하러 가기](https://kang0604.github.io/yoohyun-game/yoohyuneat.html)**

---

## 게임 설명

음식과 위험물이 섞여서 사방에서 날아옵니다.  
**먹을 수 있는 것만 골라 먹으세요!**

- 음식을 먹으면 **점수 획득** + **몸무게 증가** (+10kg)
- 먹을 수 없는 것에 부딪히면 **게임 오버**
- 시간이 지날수록 **난이도 상승**

---

## 조작 방법

| 조작 | 설명 |
|------|------|
| **방향키** (↑ ↓ ← →) | 이유현 이동 |
| **WASD** | 이동 (대체) |
| **마우스/터치 드래그** | 모바일 이동 |
| **🔊 버튼** | 소리 켜기/끄기 |

---

## 게임 정보

### 게임 난이도 (시간에 따라 상승)
- **초반:** 음식 많음, 위험물 적음
- **중반:** 음식과 위험물 혼합
- **후반:** 위험물 비중 증가, 속도 빨라짐

### 먹을 수 있는 음식 🍴
- 🍗 치킨
- 🍔 버거
- 🍕 피자
- 🍜 라면
- 🍎 과일

### 먹을 수 없는 것 ❌
- 🚗 자동차
- 🧱 벽돌
- 💻 노트북

---

## 점수 시스템

| 항목 | 설명 |
|------|------|
| **몸무게** | 60kg에서 시작, 음식 먹을 때마다 +10kg |
| **먹은 끼니** | 음식을 먹은 횟수 |
| **최대 몸무게** | 게임 중 도달한 최고 몸무게 기록 |
